# 數字森林闖關

一年級數學學習扶助的線上練習遊戲，共 18 關，涵蓋數與位值、計算、量與形、時間與生活四大類，全文搭配注音。

## 檔案說明

- `number-forest.html` — 遊戲本體，開啟即可玩（不需要伺服器，也可以直接放到任何靜態網頁空間）。
- `Code.gs` — 教師後台用的 Google Apps Script 程式碼。部署成 Web App 後，把網址貼到遊戲右上角的齒輪設定，
  就能讀取班級名單並自動記錄每個孩子每一關的作答結果到 Google 試算表。詳細部署步驟寫在檔案開頭的註解裡。

## 快速開始

1. 直接打開 `number-forest.html` 就能玩，不需要任何設定。
2. 如果要讓老師端記錄成績，照 `Code.gs` 開頭的步驟部署 Google Apps Script，再把網址貼到遊戲的齒輪設定裡。
